Send — text to Morse

Standard timing (dot = 1 unit, dash = 3, element gap = 1) at 1200/WPM ms per unit, using Character speed for the dots/dashes themselves. Farnsworth spacing stretches only the gaps between letters and words to a slower effective WPM — set it equal to Character speed for standard (non-Farnsworth) timing, or lower to keep individual characters crisp while giving your ear more time between them. Prosigns like <AR>, <SK>, <BT>, <KN>, <AS> are sent as one run-together symbol. Unsupported characters are flagged in the preview above (shown as [x?]) rather than silently dropped. Sent as a keyed audio tone through the DE‑19 path, same as the rest of this app — put the rig in a phone (USB/LSB) mode.

Send — text to RTTY (Baudot/ITA2)

Space tone 1955 Hz — computed from Mark tone and Shift (Space = Mark − Shift, or Mark + Shift with Reverse ticked below). Keep both tones inside the waterfall passband set in Settings → Waterfall display.
5‑bit Baudot/ITA2 encoding, 1 start bit + 5 data bits + stop bits, continuous-phase FSK (carrier never drops between mark and space — just like a real RTTY signal). LTRS/FIGS shift codes are inserted automatically as needed; unsupported characters are skipped. Sent as an audio tone pair through the DE‑19 path — put the rig in a phone (USB/LSB) mode, same as the rest of this app.
170 Hz shift is the near-universal ham RTTY standard — only change Mark/Shift if you know the station or system you're working expects something else.

Waterfall display

Floor/ceiling set the dB window mapped to black→full brightness on the live waterfall — this is what the browser's spectrum analyser uses to turn signal level into colour. It defaults to a wide 70 dB window; narrowing it (e.g. matching the Dynamic range setting under Radio → Transmit → Image / Text → Encode settings) makes transmitted images reproduce with correct contrast instead of washing out. Persistence smooths frame-to-frame flicker — higher trails more, lower shows faster detail.

CAT control

G90 CATs as an IC‑7100 clone — addr 70, controller E0, 19200 baud. Some firmware uses A4 instead; try it if "Read frequency" comes back empty.
The "PA" port is amp-keying output, not a PTT input. If CI‑V PTT doesn't key the rig, try RTS/DTR above.
Disconnect CAT software when done — power-cycling while connected can trigger firmware-update mode.

Audio devices

Requires a Chromium browser. TX output = DE‑19 (carries audio to the radio). Monitor = your speakers/headphones for RX audio. Preview / local playback = your speakers/headphones for the Image and Audio File "Preview" buttons and for the Numbers Station reader when it isn't keying the radio.
