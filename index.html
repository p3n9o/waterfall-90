Waterfall display

CAT control

G90 CATs as an IC‑7100 clone — addr 70, controller E0, 19200 baud. Some firmware uses A4 instead; try it if "Read frequency" comes back empty.
The "PA" port is amp-keying output, not a PTT input. If CI‑V PTT doesn't key the rig, try RTS/DTR above.
Disconnect CAT software when done — power-cycling while connected can trigger firmware-update mode.

Audio devices

Requires a Chromium browser. TX output = DE‑19 (carries audio to the radio). Monitor = your speakers/headphones. The headset microphone for Voice TX is picked on the Radio tab's Voice sub-panel.
