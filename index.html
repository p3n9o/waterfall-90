PTT & Drive

TX audio level0%
A picture with many simultaneous "on" tones (dense letter strokes, filled shapes) reads much louder to the rig than a normal voice or FT8 signal. If a receiving station sees a solid, textured block instead of your picture, that's ALC-driven splatter — turn drive down, not up, and watch the G90's ALC indicator: it should barely move.
Drive sets the level of audio sent to the radio's mic/data input. If CI-V PTT ever misbehaves, the G90's menu also supports VOX keying from the Line In audio as a fallback.
The per-column power in the image encoder is normalized so a busy region and a sparse region hit the radio with roughly the same average level, but overall drive still needs to sit low enough that ALC action stays at or near zero.

Image is converted to grayscale, then rendered as a proper inverse-spectrogram (overlap-add sine synthesis) — one row of pixels per frequency bin, one column per time slice — so it redraws as a picture in a receiving station's waterfall. Slower transmit speed = more time per column = sharper detail but a longer time on air. Fine-tune resolution in Settings → Image encode.

CAT control

The G90 speaks Icom CI-V (it CATs as an IC‑7100/IC‑756PRO clone), hex addresses shown without the "0x" — default rig address 70, controller E0, 19200 baud. The DE‑19's 4‑pin "PA" port is a TX/BAND/ALC keying output for an amplifier, not a computer‑to‑radio PTT input. If CI‑V PTT doesn't key the rig, your interface may instead expect a hardware RTS or DTR toggle — try those options above. RTS/DTR are always forced low the instant CAT connects, specifically so opening the port itself can't accidentally key the transmitter.
Xiegu's own CAT guide notes that leaving a polling CAT program connected and then power-cycling the G90 can be misread as the firmware‑update key combo — disconnect CAT software when you're done.

Image encode

Time columns — how many time-steps the image is divided into along its playback duration. Higher = smoother horizontal (time-axis) detail but a longer transmission.
Frequency rows — how many distinct tones make up the audio passband width. Higher = finer left-right picture detail, but each tone gets a narrower slice of the Min/Max frequency range above, so very high values can sound muddier on a narrow passband.
Flips apply to the rendered transmission only (the thumbnail preview above stays as-loaded), so you can compare orientation against how a receiving station's waterfall actually draws it.
Bright pixels are transmitted as "on" tones — correct for light text/shapes on a dark photo. Most ordinary photos (dark ink on paper, a printed page) are the opposite, so this is auto-ticked when an uploaded photo's average brightness looks light-background; override it if the result looks backwards.
